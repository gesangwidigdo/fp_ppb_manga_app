## Deskripsi Aplikasi
Otakulib merupakan aplikasi yang ditujukan kepada para pecinta manga untuk menyimpan manga favoritnya, melacak manga yang sedang dibaca, serta mengulas manga yang sudah dibaca. Pengguna juga bisa melihat koleksi manga yang disimpan oleh pengguna lain untuk menambah referensi manga untuk ditambahkan ke dalam koleksinya.

### Fitur yang disediakan
- Collection -> User dapat menambahkan manga-manga yang diinginkan ke dalam sebuah koleksi. Prinsipnya sama seperti playlist yang ada di aplikasi pemutar lagu. Di situ, user dapat menambahkan manga, mengedit nama koleksi, menghapus manga dari koleksi, dan menghapus koleksi
- Library -> User dapat menambahkan manga-manga yang akan dibaca ke dalam library. Nantinya, ketika user telah selesai membaca manga nya, mereka dapat menandai manga tersebut bahwa telah selesai dibaca.
- Review Manga -> User dapat menilai manga-manga yang ada. User akan diminta untuk memasukkan nilai dari bintang 1 hingga bintang 10 dan menulis ulasan.
- Search User -> User dapat melihat profil User lainnya yang sama-sama menggunakan aplikasi OtakuLib. Dengan mengunjungi profil seseorang, User tersebut dapat melihat koleksinya, library-nya, dan review yang pernah dibuat.
